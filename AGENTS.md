# AGENTS.md

Die Regeln für dieses Repository stehen in **`CLAUDE.md`** — Architektur,
Konventionen, Testschichten und die Stolperfallen. Diese Datei war einmal
eine wörtliche Kopie davon für Codex und lief hinterher; seither gilt: eine
Datei, eine Wahrheit. Wer hier landet, liest `CLAUDE.md`.

Die Wurzel-`CLAUDE.md` ist der Kern; die Begründungen zu einzelnen Bereichen
stehen in `CLAUDE.md`-Dateien der Unterordner (`tests/`, `autoclicker/`,
`autoclicker/runtime/`, `autoclicker/persistence/`, `autoclicker/editors/`,
`autoclicker/editors/sequence_studio/`, `autoclicker/platforms/`). Wer in
einem dieser Ordner arbeitet, liest die Datei dort mit.
