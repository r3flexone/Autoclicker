# Optionale Extras. NICHT noetig fuer den normalen Betrieb — jedes Feature hier ist
# per Default in der Config abgeschaltet.
#
# easyocr zieht PyTorch nach: mehrere GB Download. Nur installieren, wenn du OCR
# wirklich einschaltest (ocr_enabled). Fuer GPU-Nutzung vorher die passende
# CUDA-Variante von torch installieren — siehe README.
easyocr

# Leichtere OCR-Alternative. Braucht zusaetzlich die Tesseract-Binary:
# https://github.com/UB-Mannheim/tesseract/wiki
pytesseract

# Studio (CTRL+ALT+B fuer Sequenzen, CTRL+ALT+V fuer Scans - dasselbe Fenster).
# Die Oberflaeche ist eine Webseite in einem eigenen Fenster; auf Windows laeuft
# das ueber WebView2, das bei Windows 10/11 in der Regel schon da ist (sonst
# einmalig Microsofts "Evergreen Runtime").
#
# `dearpygui` stand hier bis zum Umbau fuer das alte Scan-Studio. Das Fenster
# gibt es nicht mehr - der Reiter "Scans" im Studio hat es ersetzt.
pywebview
